## Description
This is a simple two-player Rock, Paper, Scissors game made using Dart. Each player enters their name and chooses rock, paper, or scissors. The program checks who wins each round, keeps the score, and shows the final winner.

## How to Run

1. Make sure you have the Dart SDK installed.
2. Open a terminal in this project folder.
3. Run the game with:

   dart run rock_paper_scissors.dart

4. Follow the prompts to play!
